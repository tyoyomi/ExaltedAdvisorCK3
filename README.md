# Exalted Advisor

Crusader Kings III mod. Version **0.5.0**. Supported game version `1.20.*`.

Appoint Exalted Advisors and Exalted Vassals — mid-tier helpers under Supreme Sovereign.

## 0.5.0

- Binder-index completion (serving-count list-first; hub reindex; no world living scans)
- Shared hub intensity (Low/Mid/High) scaling council seat synergy
- Specialist packages: Marshal / Spymaster / Steward (loud bestow chooser + Assign Specialty)
- Exalted Vassal loyalty network (Soft Glue–lite + weak `favor_hook` only; not Demand Strong Hook)
- Heir tutoring aura (lifestyle crumbs while educated by an Exalted Advisor; soft peer to Reshape Heir)

Soft peers: Supreme Sovereign (Reshape Heir), Supreme Schemes (strong hooks stay there), Succession Unity (Soft Glue feel only).
